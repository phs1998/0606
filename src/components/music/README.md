## 使用方法

### 1. 添加音乐文件

编辑 `VaporwavePlayer.tsx` 文件中的 `DEFAULT_TRACKS` 数组：

```typescript
const DEFAULT_TRACKS: Track[] = [
  {
    id: '1',
    name: '曲目名称',
    artist: '艺术家名称',
    url: 'https://your-music-url.com/track1.mp3',
  },
  // 添加更多曲目...
]
```

### 2. 音乐文件要求

- **格式**: MP3、OGG、WAV 等浏览器支持的音频格式
- **来源**: 
  - 本地文件（需要上传到服务器或使用CDN）
  - 在线音乐URL
  - 建议使用HTTPS协议的URL以确保兼容性

### 3. 位置调整

播放器默认位于页面右上角，你可以：
- **拖拽移动**: 点击标题栏并拖动到任意位置
- **代码调整**: 修改组件中的 `top` 和 `right` 初始值

### 4. 自定义样式

所有样式定义在 `VaporwavePlayer.css` 文件中，你可以：
- 修改颜色变量（使用CSS变量）
- 调整尺寸和间距
- 添加新的动画效果

## 技术实现

### 核心技术
- **HTML5 Audio API**: 音频播放控制
- **Web Audio API**: 频谱分析和可视化
- **React Hooks**: 状态管理和生命周期
- **CSS3 Animations**: 视觉效果和动画
- **LocalStorage**: 持久化用户设置

### 浏览器兼容性
- Chrome/Edge (推荐)
- Firefox
- Safari
- 移动端浏览器

### 注意事项

1. **自动播放限制**: 
   - 播放器默认静音，需要用户交互（点击播放按钮）后才能播放
   - 这是浏览器的安全策略，无法绕过

2. **音频上下文初始化**:
   - Web Audio API 需要用户交互后才能初始化
   - 首次点击页面任意位置时会自动初始化

3. **CORS问题**:
   - 如果音乐文件来自不同域名，需要确保服务器设置了正确的CORS头
   - 建议将音乐文件放在同域名下或使用CDN

4. **性能优化**:
   - 频谱可视化使用 `requestAnimationFrame` 优化性能
   - 音频数据采样频率为256，平衡性能和视觉效果

## 自定义配置

### 修改默认音量

在 `VaporwavePlayer.tsx` 中修改：

```typescript
const [volume, setVolume] = useState(0.7) // 0.0 - 1.0
```

### 修改默认静音状态

```typescript
const [isMuted, setIsMuted] = useState(true) // false = 默认不静音
```

### 修改播放器尺寸

在 `VaporwavePlayer.css` 中修改：

```css
.vapor-music-player {
  width: 380px; /* 展开状态 */
}

.vapor-music-player.minimized {
  width: 320px; /* 最小化状态 */
}
```

## 故障排除

### 问题：音乐无法播放
- 检查音频URL是否有效
- 检查浏览器控制台是否有CORS错误
- 确认音频格式浏览器支持

### 问题：频谱不显示
- 确认已点击页面进行用户交互
- 检查浏览器是否支持Web Audio API
- 查看控制台是否有错误信息

### 问题：拖拽不工作
- 确认点击的是标题栏区域
- 检查是否有其他元素遮挡

### 问题：键盘快捷键不响应
- 确认焦点不在输入框内
- 检查是否有其他组件拦截了键盘事件
